# WINDOWS APP

The desk goes native on Windows: WinUI 3, WebView2, Store-bound.

## The shape

A WinUI 3 app hosting the desk in WebView2 — native chrome, web desk inside.
Same contract as everywhere else: pick a mind, stamp to arm the hands, halt
to kill the run. **Ctrl+Shift+P** summons it.

## The path to the Store

Packaged as MSIX and filed through Partner Center as "FR!sky Paperclip Desk,"
version 0.5.0.0, Productivity, age 4+. The scaffold — reviewed XAML and C#,
staged assets, submission runbook — is done; first compile happens on a
Windows build box, since .NET doesn't live on the Mac. Screenshots get
captured on real Windows, the name gets reserved in the dashboard, and the
Store association file gets committed when Visual Studio generates it.

## What stays the same

Everything that matters. Keys stay local. Pages stay untrusted. Twelve steps,
STAMP, HALT. The platform changes; the doctrine doesn't. If you've run the
Chrome desk, the Windows desk needs no manual — just the hotkey.
