# START HERE

The agent desk lives in your browser. Pick a mind, type a task, watch it work.

FR!sky Paperclip 0.5.0 sits in the Chrome side panel. It plans up to 12 steps,
reads the page you point it at, and clicks only when you say so. Two minds —
Grok or GPT — one desk, no accounts, no servers in the middle.

## The thirty-second version

- Open the side panel. Pick Grok or GPT. Paste your own API key in Options.
- Type a task. Press RUN. The mind plans, Clip acts, the log shows everything.
- **STAMP** arms Clip's hands. **HALT** kills the run instantly.
- The page is untrusted data. Treat it that way and you'll never be surprised.
